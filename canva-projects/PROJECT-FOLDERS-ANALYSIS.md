## Usage

- **Finalized output:** `canva-projects/finalized-projects/` — one folder per
  project (slug from name), **max 3 images** from Site Pictures, plus matched
  text from Canva extracted slides.
- **Build script:** `node canva-projects/build-finalized-projects.js` (from repo
  root).
